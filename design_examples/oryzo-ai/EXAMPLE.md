# ORYZO AI 디자인 예시

이 예시는 현재 프로젝트의 디자인 세트를 그대로 보관한 샘플이다.

새 프로젝트에서 이 스타일을 쓰려면 아래 폴더를 프로젝트 루트로 복사한다.

```text
design_examples/oryzo-ai/design_asset/
```

복사 후 대상 프로젝트에서는 아래 경로가 활성 디자인 세트가 된다.

```text
design_asset/DESIGN.md
design_asset/tokens.json
design_asset/variables.css
design_asset/theme.css
design_asset/typography-options.json
```

composition 작성 전에는 `design_asset/DESIGN.md`를 먼저 읽고, 폰트, 자간, 줄간격은 `typography-options.json`과 `variables.css`를 함께 참조한다.
